# 2026-10-22: vactrol part

Branch `claude/project-thread-5yafuv`. Gady asked how to make a vactrol; the first answer was a
subcircuit built from two VCCSs (file in the project's `vactrol/` folder), then Gady picked a
built-in part. See [docs/deviations/vactrol.md](../deviations/vactrol.md).

## Done

- `VactrolElm` (packages/elements/src/elm/VactrolElm.ts), a `CustomCompositeElm` whose model is
  built from its values: presets VTL5C1, VTL5C2, VTL5C3, VTL5C4, NSL-32SR3 (datasheet values)
  and Lamp + LDR, or custom values; LED or lamp source.
- Saved as an upstream subcircuit plus extra attributes, so CircuitJS1 opens it as a chip that
  runs the same. Loading picks the class from the record (`classNameForXmlRecord`), also for a
  vactrol inside another subcircuit.
- View (packages/elements/src/view/vactrol.ts): box, glowing LED (or lamp with its filament
  colour), arrows, resistor in a circle shaded by the light level, model name, fixed-width
  resistance readout when values are shown. Info box: R, Vd, source current, light level.
- Parts list entry (Active Building Blocks, after Optocoupler) with search words; the new
  property names in all 16 languages (by Claude, not checked by native speakers).
- Tests: packages/format/src/vactrol.test.ts.
- Obsidian: the part lives in the elements package and draws through the shared renderer, so it
  should work in note blocks and the plugin's editor; not tried in Obsidian.
